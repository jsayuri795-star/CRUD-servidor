# Como executar o projeto
1. Clone o repositorio
 ```JSON
git clone url_do_repositorio
```
2. Entre na sua pasta do projeto e instale as dependências
```JSON
npm install
```
e instale o express cors

3. Inicie o seu servidor
```JSON
npm run dev
```
e então aparecerá no terminal

```JSON
Servidor respondendo em: http://localhost:porta
```
4. No body do thunder coloque os pedidos e clique em "SEND"
